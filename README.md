# ScholarReel — public pages

Privacy policy, terms and the account-deletion page for the ScholarReel
Android app (`com.scholarreel.app`), served via GitHub Pages.

This repository is public **only because GitHub Pages requires it on the free
plan**. The application source lives in a separate private repository. Nothing
here is secret: these are documents intended to be read by anyone, including
Google Play reviewers.

Served at https://medifoundrydev.github.io/scholarreel-site/

The canonical copies live in the main repo under `docs/`. Edit them there and
copy across, so the two do not drift.
